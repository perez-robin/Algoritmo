1. Verificar si un Número es Primo (Módulo 1 y 2)

Funcion Booleano EsPrimo(Entero num)
    Entero i, divisores
    Si num <= 1 Entonces
        Retornar Falso
    FinSi
    
    divisores <- 0
    Para i <- 1 Hasta num Con Paso 1 Hacer
        Si (num MOD i == 0) Entonces
            divisores <- divisores + 1
        FinSi
    FinPara
    
    Si divisores == 2 Entonces
        Retornar Verdadero
    Sino
        Retornar Falso
    FinSi
FinFuncion
Explicación paso a paso:
• Línea 3: Si el número es 1 o menor, no es primo (caso especial).
• Línea 8: Usamos un contador divisores que inicia en 0.
• Línea 9: El bucle Para prueba dividir num entre todos los enteros desde 1 hasta num.
• Línea 10: El operador MOD obtiene el resto. Si el resto es 0, es un divisor exacto.
• Línea 15: Si exactamente 2 números lo dividieron (el 1 y él mismo), es primo.

2. Paso por Referencia: Intercambiar 2 Variables (Módulo 2)

Procedimiento Intercambiar(Por Referencia Entero a, Por Referencia Entero b)
    Entero aux
    aux <- a
    a <- b
    b <- aux
FinProcedimiento
Explicación paso a paso:
• Por Referencia: Es indispensable la palabra reservada Por Referencia para que los cambios persistan fuera del procedimiento.
• Línea 3: Guardamos el valor original de a en la variable temporal aux para no perderlo.
• Líneas 4-5: Le pasamos el valor de b a a, y luego asignamos aux a b.

3. Suma Recursiva de los Primeros N Números (Módulo 3)

Funcion Entero SumaRecursiva(Entero n)
    // CASO BASE: Detiene las llamadas recursivas
    Si (n <= 0) Entonces
        Retornar 0
    Sino
        // CASO RECURSIVO: Suma 'n' con el resultado de la función con (n - 1)
        Retornar n + SumaRecursiva(n - 1)
    FinSi
FinFuncion
Explicación paso a paso:
• Caso Base: Cuando n llega a 0, devuelve 0 sin volver a llamar a la función.
• Caso Recursivo: Si n = 3, calcula 3 + SumaRecursiva(2). Se apila en memoria hasta llegar al Caso Base y luego desapila devolviendo el total (3 + 2 + 1 + 0 = 6).
