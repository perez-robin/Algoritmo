Fórmulas de Pseudocódigo

Plantillas estándar para memorizar y escribir en papel.

1. Condicional `Si - Sino`

Si (condicion_1) Entonces
    // Bloque 1
Sino Si (condicion_2) Entonces
    // Bloque 2
Sino
    // Bloque por defecto
FinSi

2. Bucles (`Para` y `Mientras`)

// Bucle PARA
Para i <- 1 Hasta N Con Paso 1 Hacer
    // Repeticion N veces
FinPara

// Bucle MIENTRAS
Mientras (condicion) Hacer
    // Repeticion
    i <- i + 1  // ¡Avanzar contador!
FinMientras

3. Subalgoritmos

// FUNCIÓN (Con retorno)
Funcion Entero Sumar(Entero a, Entero b)
    Retornar a + b
FinFuncion

// PROCEDIMIENTO (Sin retorno)
Procedimiento Imprimir(Cadena msg)
    Escribir msg
FinProcedimiento

4. Esqueleto Recursivo

Funcion Entero Factorial(Entero n)
    Si (n <= 1) Entonces
        Retornar 1  // CASO BASE
    Sino
        Retornar n * Factorial(n - 1)  // CASO RECURSIVO
    FinSi
FinFuncion
