Fórmulas de Pseudocódigo para Memorizar

Estructuras estándar que debes escribir exactamente igual en tu examen escrito a mano.

1. Estructura Condicional Completa (`Si - Sino`)

Si (condicion_1) Entonces
    // Bloque si se cumple condicion 1
Sino Si (condicion_2) Entonces
    // Bloque si se cumple condicion 2
Sino
    // Bloque por defecto
FinSi

2. Bucles (`Para` y `Mientras`)

// Bucle PARA (Cantidad de iteraciones conocida)
Para i <- 1 Hasta N Con Paso 1 Hacer
    // Codigo a repetir N veces
FinPara

// Bucle MIENTRAS (Condición al inicio)
Mientras (condicion) Hacer
    // Codigo a repetir
    i <- i + 1  // ¡OBLIGATORIO: Avanzar la variable de control!
FinMientras

3. Subalgoritmos (Función vs Procedimiento)

// FUNCIÓN: Procesa datos y DEVUELVE UN VALOR
Funcion Entero CalcularSuma(Entero a, Entero b)
    Entero resultado
    resultado <- a + b
    Retornar resultado  // ¡OBLIGATORIO!
FinFuncion

// PROCEDIMIENTO: Ejecuta acciones SIN devolver valor
Procedimiento ImprimirMensaje(Cadena texto)
    Escribir "MENSAJE: ", texto
FinProcedimiento

4. Esqueleto Universal de Recursividad

Funcion Entero CalcularFactorial(Entero n)
    // 1. CASO BASE (Condición de parada que rompe la recursión)
    Si (n <= 1) Entonces
        Retornar 1
    Sino
        // 2. CASO RECURSIVO (Se llama a sí misma reduciendo el problema)
        Retornar n * CalcularFactorial(n - 1)
    FinSi
FinFuncion
